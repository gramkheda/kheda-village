## Setup

1. `index.html`, `style.css` और `script.js` को एक ही folder में रखें।
2. `images` folder बनाकर अपनी मौजूदा village, railing और solar images उसमें रखें।
3. `index.html` को browser में खोलें।
4. वेबसाइट internet के बिना भी सामान्य HTML/CSS/JS हिस्सों में चलेगी; Google Map के लिए internet connection जरूरी है।

## Important

इस package में आपकी image files शामिल नहीं हैं क्योंकि इस turn में उपलब्ध uploaded files में image assets नहीं थे। अपनी existing `images` folder को इस package के अंदर रखें और ऊपर दिए गए filenames वही रखें।
